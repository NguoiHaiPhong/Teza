Native Rust + Tauri Desktop Client

Fast, Private Desktop Messaging with Encrypted Local & Cloud Vault

Teza is a lightweight desktop messaging application built with Rust and Tauri. It features a local AES-256-GCM media vault, instant multi-language search, voice & video calls, and optional end-to-end encrypted backup to your own Google Drive.

Download Teza for Windows Read Privacy Policy

Local Encrypted Media Vault

Photos, videos, voice notes, and attachments are cached locally in 64 KiB AES-256-GCM chunks protected by Windows DPAPI with configurable storage folder and LRU quota.

Optional E2EE Google Drive Sync

Back up your encrypted media and chat history deltas into a dedicated Teza Vault folder in your personal Google Drive using only the narrow drive.file scope.

User-Controlled Cloud Storage

View real-time Drive quota usage, inspect storage by conversation or file size, and selectively prune old cloud backups at any time directly inside Teza Settings.

Google Drive Permissions & Transparency

Teza requests only the non-sensitive https://www.googleapis.com/auth/drive.file scope so the app can exclusively access files it creates inside your Teza Vault folder. Teza never accesses your other Google Drive files, encrypts all backups on your computer before upload using your Sync Passphrase, and operates no central servers storing your data.
